# How to create a workspace

In this tutorial, you’ll learn how to create and configure your first workspace.

## Setup Instructions

1 - On the left panel, click *Research Hub --> My Hub* and select *New Workspace*.

2 - Complete the workspace form. 

<img src="../images/workspace-form.png" style="border: 2px solid black;">

3 - Click *Save Workspace* to proceed.

4 - If you need to edit the metadata of your workspace at any point, you can do so by clicking the *Edit* button in the top right corner.

5 - Click the *Edit* button next to *Catalog Assets*. This will open a dataset search window.

6 - Search for the dataset corresponding to your workspace. Once identified, click *Add*.

<img src="../images/add-dataset.png" style="border: 2px solid black;">

7 - Click the *Edit* button next to *Workspace Codebase*. Paste the demo GitHub repository wit the source code for your project. Then click *Add from external link*. Close the window once the repository is added. 

<img src="../images/add-repository.png" style="border: 2px solid black;">

We have finished setting up our first workspace. Now, we will run it using the JupyterHub service. Proceed to the next tutorial: [How to launch workspace](./launch-workspace.md).
